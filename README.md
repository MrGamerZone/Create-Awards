Create: Awards
A Minecraft 1.21.1 / NeoForge addon for Create that adds physical awards, trophies, plaques, and creator PlayButtons.
Required dependency
Create is required. The mod declares Create as a required dependency in `neoforge.mods.toml`.
The development build uses Create 6.0.8 for Minecraft 1.21.1 / NeoForge. The mod metadata accepts compatible Create 6.x releases.

Build
Requires Java 21 and a NeoForge 1.21.1 development environment.
On Windows:
```text
gradlew.bat build
```
The compiled JAR will appear in `build/libs/`.
